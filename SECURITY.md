# Security Policy

## Reporting

Please report security issues through a private GitHub Security Advisory. Do not include real Feishu/Lark message bodies, screenshots, user IDs, chat IDs, document tokens, meeting IDs, approval instance codes, app credentials, access tokens, authorization URLs, or device codes in public Issues.

## Scope

The repository contains read-only orchestration instructions and local helper scripts. A report is especially useful when it concerns accidental persistence of business data, cross-tenant state reuse, identity confusion, unsafe authorization handling, credential leakage, or a path that triggers a Feishu write operation without explicit user intent.
