# 首次安装与运行配置

## 最小配置

```text
report_time: 用户确认的 HH:MM
timezone: 用户确认的 IANA 时区
baseline_days: 7
delivery: 当前 Agent 任务或用户明确指定的受支持位置
```

## 流程

1. 执行 `doctor.py`，验证 CLI、用户身份和各数据域能力。
2. 缺少报告时间或时区时只询问一次。
3. 建立工作地图草案并等待用户确认。
4. 使用宿主的周期任务能力创建或更新一条每日巡检，避免重复任务。
5. 执行 7 天基线；成功后才推进检查点。
6. 后续窗口从上次成功点延续，错过运行时明确显示实际覆盖范围。

宿主缺少周期任务能力时，只交付手动运行方式。调度是否创建成功必须由宿主状态回读证明。

## 迁移

- 状态 schema 不兼容或损坏：先备份原文件，再重新初始化并重做 7 天基线。
- 修改报告时间：只影响后续窗口，不重扫无关历史。
- 更换飞书 profile 或租户：创建独立私有状态；不得沿用旧租户指纹和工作地图。
